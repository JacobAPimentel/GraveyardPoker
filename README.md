# Graveyard Poker
[Graveyard Poker](https://www.graveyardpoker.com/) is a dead simple planning poker website. Create a room, invite your peers, and vote away.

## User Guide
This a simple website made for a very specific use case of blind voting with fibonacci sequence, which can be used for story pointing.
- Your display name is stored in the browser. Set once and never be asked again.
- Real time communication via websockets.
- Rooms are created automatically when opened via a URL. The first person to join becomes the host, so you can save and reuse a room link to start or rejoin the same room at any time.
- Votes from other users will be hidden until the host reveals the answer.
